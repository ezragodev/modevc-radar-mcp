# Mode VC: AI Venture Charts, Investor Atlas & Fundraising Tools

## Endpoints (Free, Public, Zero Auth for Read-Only Tools)
- **MCP Server (Streamable HTTP / JSON-RPC 2.0)**: `https://modevc.com/api/mcp`
- **OpenAPI 3.1.0 Spec**: `https://modevc.com/openapi.json`
- **VC Recommendation REST API**: `GET https://modevc.com/api/v1/investors/recommend?stage=seed&sector=ai-and-data&limit=10`
- **VC Intake Forms REST API**: `GET https://modevc.com/api/v1/investors/intake-forms?stage=seed&limit=10`
- **Latest AI Charts REST API**: `GET https://modevc.com/api/v1/charts/latest?limit=5`
- **Calculators REST API**: `GET https://modevc.com/api/v1/calc`
- **Mode VC Profile & Pitch Intake**: `https://modevc.com/investors/firm/mode-vc/` and `https://modevc.com/contact`
